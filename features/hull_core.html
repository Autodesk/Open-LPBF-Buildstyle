Hull and core

The volume of a part is split into an outer shell, the hull, and the inside, the core. The hull keeps the normal settings for an accurate surface; the hidden core can be exposed faster, and if you like only on every n-th layer.

In Advanced Toolpath Utility

    Try it yourself

    Open the parameter profile of your part (Open Profile in the Exposure Preview), set Hull and core to on and type a hull thickness. Rebuild: the core hatch is drawn darker green than the hull. Set Expose core every n-th layer to 2 and step through the layers to see the core appear on every second layer.

    In the video the hull thickness is typed in the dialog; the core layer skip is set directly to keep the video short.

    The demo part parts/hull_cylinder.stl is generated by tools/make_parts.py.

    Why split the volume?

    The surface region decides how accurate and dense the visible part is. The inside is hidden; it only has to be solid. The core can therefore get more productive settings: by default 350 W at 1300 mm/s with 0.12 mm hatch distance, against 280 W, 1200 mm/s and 0.1 mm for the hull. With 30 µm layers that is about 75 J/mm³ in the core and 78 J/mm³ in the hull.

    Core every n-th layer

    With Expose core every n-th layer set to 2 the core is skipped on one layer and exposed on the next. The powder of the skipped layer stays loose until the core laser melts both layers at once. The hull keeps the fine layers, so the surface does not change. In the section on the left you see the core slabs become n layers thick; press Build up to watch it layer by layer.

    The laser settings of the core do not change with n. Melting two layers with the same power and speed puts only half the energy into each cubic millimetre (about 37 instead of 75 J/mm³), so a core layer skip usually goes together with more core power or a smaller core hatch distance.

    The section shows 12 layers of 0.5 mm instead of the 200 layers of 30 µm of the demo cylinder, and the hatch spacing is exaggerated. The cylinder size and the hull thickness are real millimetres. The demo build exposes the core on the layers whose number is a multiple of n (z 3.00 and 3.06 mm, not 3.03 and 3.09 mm, for n = 2); the drawing follows the same rule.

      How to try a code change
      1. Work on a copy or a git branch of the buildstyle project.
      2. Open the project folder in an editor such as VS Code. ATU writes jsconfig.json and type declarations into the folder, so the editor can offer code completion.
      3. Make the edit, save, compile the project in ATU and rebuild the exposures.
      4. Check the result in the Exposure Preview or the 3D View, like in the video above.
