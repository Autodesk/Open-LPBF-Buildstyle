Layer skip

Not every vector type has to be exposed on every layer. The layer skip exposes a vector type only on every n-th layer; on the other layers it produces no paths at all. The layer offset chooses which layers those are, so different vector types can take turns.

In Advanced Toolpath Utility

    Try it yourself

    Open the parameter profile of your part (Open Profile in the Exposure Preview), expand First border (beam compensation) › Layer skip and set Expose every n-th layer to 2. Rebuild and step through a few layers: the border is only drawn on every second one.

    The part outline is drawn in red as well, so the video hides the original and preprocessed part (left bar of the Exposure Preview) and zooms to the edge. The demo also counts the border paths from the toolpath data: 96 edges on every layer before the change; with n = 2 only on layers 101 and 103, with offset 1 only on 100 and 102. The demo part parts/hull_cylinder.stl is generated by tools/make_parts.py.

    Every n-th layer

    The drawing is a cut through 16 layers of the cylinder from the video: the border at both walls, the hatch in between. With Expose every n-th layer = 2 the border is exposed on every second layer and missing on the others. A skipped vector type produces nothing on that layer, not a thinner or weaker path.

    The offset

    A layer is exposed if layer index − offset is a multiple of n. The index counts from 0 at the lowest layer of the part, so ATU's layer 101 is index 100. With n = 2 and offset 0 the border is on layers 101 and 103; offset 1 moves it to 100 and 102, as in the video. Offsets of n or more repeat: with n = 2, offset 3 is the same as offset 1.

    Taking turns

    Give two vector types the same n and different offsets, and they alternate: try border and hatch both on every second layer, with offsets 0 and 1. The explainer warns when a layer is left without any exposure.

    Exposing a vector type less often saves time and heat, but the powder layers in between are then melted together with the next exposure: the energy has to be raised for it. For the core of a part, Hull and core has its own setting, Expose core every n-th layer; for supports see Wall supports.

    Parameters

    ParameterDefaultMeaning
    Expose every n-th layer1 (1–100)1 = every layer, 2 = every second layer, …
    Layer offset0 (0–99)Index of the first exposed layer; taken modulo n.

    The group exists under First border, Following borders, Fill contours, every hatch group (Volume, Core, Downskin, Upskin, Support hatching) and Wall supports, each with its own two values.

      How to try a code change
      1. Work on a copy or a git branch of the buildstyle project.
      2. Open the project folder in an editor such as VS Code. ATU writes jsconfig.json and type declarations into the folder, so the editor can offer code completion.
      3. Make the edit, save, compile the project in ATU and rebuild the exposures.
      4. Check the result in the Exposure Preview or the 3D View, like in the video above.
