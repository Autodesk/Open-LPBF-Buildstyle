Build order, scanning order and gas flow

After all paths of a layer exist, the buildstyle decides in which order the laser exposes them. The build order says whether it works vector type by vector type over the whole plate, part by part, island by island, or path by path regardless of parts and islands. The scanning order ranks the vector types. The gas flow direction makes the laser start downstream, so spatter is blown onto areas that are already exposed.

    Global: one sweep over all parts

      With a chessboard hatch every field is its own hatch block. Platform places the blocks of an island by the position of the island, so the fields of a long bar are exposed together before the laser moves on. Global places every block and contour by its own position: the fields of the bar and the squares next to it are exposed in one sweep against the gas flow.

      To try it, load parts/order_strip.stl (a 48 mm bar and three squares, generated by tools/make_parts.py), set the volume hatch pattern to chess and switch Build order from Platform to Global in the platform profile.

      Build order

      Platform exposes one vector type over the whole plate, then the next: with the defaults, all hatches, then all first borders. Model finishes one part before the next; on a plate with a single part it is the same as Platform. Island finishes one island, its hatch and its border, before the laser moves on. Supports of a part come before its islands. Global works vector type by vector type like Platform, but places every path by its own position: parts and islands are no sort level. In this drawing every island is a single hatch block, so Global looks almost like Platform (islands equally far downstream go by their position across the flow instead of their island id); the real difference shows with striped or chessboard hatches, as in the second video.

      Sorting is the first step after the paths are made: the laser assignment, the power optimization and the time estimate follow this order.

      Scanning order

      Every vector type has a number; smaller numbers are exposed first. The volume hatch has 40, the first border 80, so the border comes last. Set the first border below 40 and it comes first: on the whole plate in the Platform mode, inside every island in the Island mode.

      Gas flow

      The shielding gas carries spatter and fumes downstream. The buildstyle sorts the islands by their position along the flow and starts with the one furthest downstream, so the laser works against the flow and always melts in clean gas. With 0° the gas flows to +X and the right column comes first; with 90° it flows to +Y and the top row comes first. Islands at the same position along the flow keep the order of their island ids.

      The gas flow angle also turns the limitation window of the hatch rotation.

      Several parts

      Tick Six separate parts to treat every island as its own part. Sort models against gas flow (on by default) ranks the parts by the centre of their bounding box, furthest downstream first; the rank is the same in every layer. Switched off, the parts keep the order in which they were added to the plate. In the Model and Island modes the rank decides which part is finished first. In the Platform mode it only matters when it is off: then, inside one vector type, the part order comes before the position along the gas flow.

      The order in which the six parts were added is assumed to follow the island ids of the demo.

        How to try a code change
        1. Work on a copy or a git branch of the buildstyle project.
        2. Open the project folder in an editor such as VS Code. ATU writes jsconfig.json and type declarations into the folder, so the editor can offer code completion.
        3. Make the edit, save, compile the project in ATU and rebuild the exposures.
        4. Check the result in the Exposure Preview or the 3D View, like in the video above.
