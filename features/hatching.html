Hatching patterns

The inside of every layer is filled with parallel laser lines, the hatch. The pattern decides how long these lines get and in which directions they run: meander, stripes, chessboard, hexagon or offset rings.

In Advanced Toolpath Utility

    Try it yourself

    Open the parameter profile of your part (Open Profile in the Exposure Preview), expand Hatching › Volume hatching and choose a Pattern. Rebuild and zoom into the Exposure Preview; step one layer up to see the 67° rotation.

    For the stripes, the video sets the stripe overlap to −0.3 mm so the seams between the strips become visible gaps; with the default overlap of +0.05 mm neighbouring strips overlap and the seams cannot be seen. The other patterns use their defaults.

    The demo part parts/hatch_plate.stl is generated by tools/make_parts.py.

    Why patterns?

    Every laser line melts the powder, and the melt shrinks while it cools down within milliseconds. That leaves residual stress in the part, largest along the scan direction and growing with the length of the vectors. Long vectors also give the previous line more time to cool before the next one is placed beside it. The patterns limit this in different ways. Compare the longest vector: meander lines cross the whole plate, stripes, chess fields and hexagons keep them short.

    • Meander: one set of parallel lines, every second one reversed. Simple, few jumps.
    • Stripes: strips of stripe width; the lines run across each strip.
    • Chessboard: square fields; neighbouring fields are turned by 90°.
    • Hexagon: hexagonal cells in three groups at +0°, +60° and +120°, so touching cells never share a direction.
    • Offset: rings parallel to the outline, d/2 + k·d inside; no line ends at the border.

    Scan direction and order

    The arrows show the direction of every vector. Inside a hatch the direction always alternates from line to line: the laser runs back on the next line instead of jumping back to the start side. The buildstyle has no setting for this; every pattern is hatched this way. Press Play creation order to see the order:

    • The hatch front moves against the gas flow (optimized block sort): the lines furthest downstream come first, so spatter and fumes are blown onto areas that are already exposed. Where the layer angle would expose the lines downstream, the rotation turns it by 180°: the same lines in the opposite order (see Hatch rotation).
    • Stripes are taken one after the other, downstream first (improved stripe sorting). By default every stripe runs in the same direction, against the gas flow: unidirectional stripes, with a jump back after each stripe. Alternate stripe direction reverses every second stripe, so the laser continues where the previous stripe ended; those stripes then run with the gas flow.
    • Chessboard: first all fields of one colour, then the others with the lines turned by 90°. Hexagon: group 0, then 1, then 2. Inside each group the fields are taken downstream first.
    • Offset: one closed ring after the other, every second ring in the opposite direction. The rings start at the outside; Expose from inside to outside starts with the innermost ring.

    Overlap, minimum length and hatch offset

    Stripes, chess fields and hexagons overlap their neighbours by a small distance (default 0.05 mm), so the seams between them are melted completely. Set a negative overlap to open a gap and see the seams, as the video does for the stripes. The slider goes further than useful values so the effect becomes visible at this scale.

    Vectors shorter than the minimum vector length are removed (dashed red): the laser needs some distance to reach a stable melt pool, and tiny vectors mostly add jump time. The hatch offset moves the hatch area (dashed line) away from the innermost contour; a negative value lets the hatch overlap the contour.

    Rotation from layer to layer

    The whole pattern turns by 67° per layer. 67 has no common divisor with 180, so the same direction only comes back after 180 layers; tracks of neighbouring layers never lie exactly on top of each other. Move the layer slider and watch the compass: stripes, fields and cells rotate around the platform origin together with the lines.

    The line spacing on the left is exaggerated (the real hatch distance is 0.1 mm) so the single lines stay visible. Stripe width, field size and hexagon side are real millimetres on the 40 × 28 mm demo plate, with the gas flow at its default of 0° (towards +X). The block order is a simplified model of ATU's block sort: it may split a hatch into more blocks, for example around the notch, and the buildstyle's scanning order still decides which vector types come first.

      How to try a code change
      1. Work on a copy or a git branch of the buildstyle project.
      2. Open the project folder in an editor such as VS Code. ATU writes jsconfig.json and type declarations into the folder, so the editor can offer code completion.
      3. Make the edit, save, compile the project in ATU and rebuild the exposures.
      4. Check the result in the Exposure Preview or the 3D View, like in the video above.
