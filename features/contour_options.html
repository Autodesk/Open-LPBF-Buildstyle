Contour options: start point shift and line stipple

Every contour type has two options for its closed rings. The start point shift moves the point where a ring starts and ends, so the small seams of many layers do not stack up into a line on the part's wall. The line stipple cuts the ring into dashes that are exposed in several passes, so each piece of the border can cool before its neighbour is melted.

In Advanced Toolpath Utility

    Try it yourself

    Turn on Start Points in the left bar of the Exposure Preview: small circles mark where each path starts (red on the border, green on the hatch). Step through a few layers, then open the profile, expand First border › Start point shift and pick a mode. Rebuild and step through the same layers again.

    In the demo the border of layers 100 to 103 starts at the same point with Off and at four different points with Random + previous layers. With Line stipple on and 2 mm dashes, the first border of layer 100 has 363 segments instead of 288, and the animation shows the dashes and then the gaps. The demo part parts/hull_cylinder.stl is generated by tools/make_parts.py.

    Seams

    A closed ring starts and ends at the same point. There the melt track overlaps a little or leaves a tiny gap: a seam. With the start point shift Off, every layer starts at the same point, and the seams form a vertical line on the wall, a "zipper". The explainer shows the first border of the 24 mm cylinder for 30 layers: from the top, and with the side wall unrolled.

    Four modes

    Random picks any point of the ring. It can still land close to the seam of the layer below. Previous layers takes the first of up to 64 points along the ring that keeps the minimum distance to the start points of the compared layers, so the seam walks around the part step by step. Random + previous layers checks the same points in random order: random, but never too close to the last seams. Random is the default.

    Line stipple

    With the stipple on, the ring becomes dashes. With 2 passes the laser exposes every second dash on the way round, then the gaps. Each dash has a full round to cool before its neighbour is melted. A small overlap makes sure the dashes of different passes join without a gap.

    The joints between the dashes are small seams of their own. With Random dash start (on by default) the dash pattern begins at a random point in every layer, so the joints do not stack on top of each other. The grey ticks outside the ring mark the joints of the layer below. Without the option the dashes begin at the start point of the ring. In this view that start point stays the same in every layer (as with start point shift Off), so the ticks line up with the joints of the current layer. With a start point shift the whole pattern moves along with the start point.

    The dashes are open paths. The modes with history then have no effect on that contour, and the Build Style Log warns once. The random start points in the explainer come from their own generator, so they differ from ATU's; the rules are the same.

      How to try a code change
      1. Work on a copy or a git branch of the buildstyle project.
      2. Open the project folder in an editor such as VS Code. ATU writes jsconfig.json and type declarations into the folder, so the editor can offer code completion.
      3. Make the edit, save, compile the project in ATU and rebuild the exposures.
      4. Check the result in the Exposure Preview or the 3D View, like in the video above.
